# BLACKWOOD-18

A small web project that creates an old corrupted computer terminal.

built using HTML, CSS & JavaScript

link -

## features
- old style BIOS/terminal
- red crt style visual blurry effect 
- system config and memory
- many input commands **use "help" commands to know about all the commands**
- glitch effect

### commands
help
about
clear
audio
manifesto
disturb

##  Run locally

1. clone the repo
``` git clone https://github.com/nAItiklearn/BLACKWOOD-18
```
2. open website in browser using preview or live server(no packages required)
